Paquete y Comandos para Subir a GitHub

Listo para subir: Descarga tu archivo index.html directamente o usa localStorage para guardar cambios en el navegador.

1. Archivo README.md recomendado

# CosechaSolidaria MX

Plataforma web y móvil (front Material Design 3) sin fines de lucro (**0% comisión**) para rescatar cosechas maduras, excedentes de corte y cajas surtidas directamente de agricultores y cooperativas mexicanas.

## Funcionalidades
- 3 Perfiles diferenciados: Comprador (con Club Cosecha y membresías), Publicador (con comparador de precios de tienda) y Administrador.
- Filtrado automático por cercanía real (km) con GPS o ciudad.
- Base de datos local en `localStorage` con exportación e importación `.json`.

2. Comandos Git para subir tu repositorio

git init
git add index.html README.md
git commit -m "Subir CosechaSolidaria MX"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/cosechasolidaria-mx.git
git push -u origin main

3. Activar enlace público gratis (GitHub Pages)

En tu repositorio de GitHub entra a Settings → Pages → Source: Deploy from a branch, elige la rama main y carpeta / (root), y guarda.
